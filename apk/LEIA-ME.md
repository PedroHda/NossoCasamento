# Instalar o Nosso Casamento

Baixe [NossoCasamento-2.1.1.apk](https://github.com/PedroHda/NossoCasamento/raw/refs/heads/master/apk/NossoCasamento-2.1.1.apk) no Android e abra o arquivo para instalar.

Esta versão simplifica os cadastros e corrige a página deslizando para os lados. Usa a mesma assinatura da 2.1.0 para atualização direta.

- Android 7.0+ com WebView/Chrome 110+.
- Nome no celular: **Nosso Casamento**, com ícone de alianças.
- Inclui contagem para **24/07/2027**, com data/horário editáveis, pagamentos, parcelas, comprovantes, cronograma, relatórios e lixeira.
- Funciona offline e mantém os dados localmente. Não há banco, login ou sincronização entre aparelhos.
- Convites usam confirmação por código importado manualmente pelo casal.
- Inclui núcleos familiares, visão por mesas, lista da casa e conexão opcional à agenda Android.
- Versão de demonstração com assinatura de debug. Notificações precisam de permissão e ainda devem ser conferidas em um aparelho físico.
- Confira a integridade usando o arquivo [SHA-256](NossoCasamento-2.1.1.apk.sha256).

**A chave de assinatura é diferente da usada no APK 2.0.0.** Exporte e guarde o backup antes de reinstalar; importe o JSON no app novo. Não desinstale antes de preservar seus dados. Os dados iniciais são fictícios; personalize em **Configurações**.

Consulte o [guia Android](../docs/android.md) para instalação, atualização, armazenamento e compilação. Os APKs anteriores permanecem nesta pasta.
